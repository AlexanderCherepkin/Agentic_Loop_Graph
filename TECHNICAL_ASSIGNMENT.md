# ТЕХНИЧЕСКОЕ ЗАДАНИЕ (ТЗ)
## Разработка премиального сайта кухонь-гриль

### 1. Общая информация

#### 1.1. Назначение проекта
Разработка современного, адаптивного и производительного лендинг-сайта для компании по премиальным кухням-гриль. Сайт должен демонстрировать экспертность бренда, привлекать клиентов через визуальное воздействие и предоставлять инструменты для оценки стоимости.

#### 1.2. Целевая аудитория
- Владельцы частных домов с террасами/садами
- Владельцы загородных коттеджей  
- Любители барбекю и гриля
- Ценители премиального сервиса

## 2. Технологии и стек

### 2.1. Основной стек технологий

| Компонент | Технология | Описание |
|-----------|------------|----------|
| **Фреймворк** | React 18.x/19.x | SPA-архитектура с hooks |
| **Build Tool** | Vite | Быстрая сборка и разработка |
| **Стилизация** | Tailwind CSS | Утилитарный CSS-фреймворк |
| **Анимации** | Framer Motion | Плавные анимации UI |
| **Формы** | Formik + Yup | Валидация и управление формами |
